# AskML: AI-Powered Chatbot for Machine Learning Q&A

AskML is an interactive AI chatbot that answers questions related to machine learning concepts, models, and applications. Designed using Streamlit and powered by GPT language models, AskML serves as a virtual assistant for users seeking quick insights into machine learning topics.

This project demonstrates the creative use of AI-assisted coding tools, prompt engineering, and conversational UI design.

## 🚀 Features
- Responds to a wide range of machine learning questions
- Real-time chatbot interface powered by GPT models
- Built and iterated using AI coding tools (ChatGPT, Copilot)
- Deployed with Streamlit for easy interaction

## 🛠 Technologies Used
- Python
- Streamlit
- OpenAI / GPT models
- Pandas (optional for additional data handling)
